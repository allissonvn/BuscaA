# Busca A* – Rotas em um mapa de cidade virtual

Aplicação Java com interface Swing que encontra o menor caminho entre dois
pontos de um mapa com ruas de mão única e de mão dupla, usando o algoritmo A*.

## Funcionalidades
- Seleção de origem e destino com clique no mapa
- 3 heurísticas: Manhattan, Euclidiana e Chebyshev
- Exibição do caminho, do custo total e do número de nós expandidos

## Tecnologias
Java, Swing, estruturas de dados (PriorityQueue, HashMap, HashSet)

## Como executar
Abra no IntelliJ IDEA e execute a classe `BuscaA`.
